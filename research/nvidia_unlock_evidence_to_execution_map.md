The objective is to safely implement and validate **a distinct GA102 and AD102 Windows preboot transaction** that can restore the currently restricted Tensor Core FP32-accumulation issue rate, hand off to the **unmodified** Windows NVIDIA driver, and demonstrate the actual performance and numerical result on each card. Tensor Cores already work; this is not a claim to add missing Tensor Cores or automatically double application throughput.
